# iPhone Simulator Web Starter

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root.
3. Open Settings → Pages. Select deploy from branch `main`, folder `/ (root)`.
4. Open the generated public URL on your iPhone.

## Included
- iPhone-style lock screen, home screen and app switcher
- PLUS CHAT fan/artist mode, simulated feed and DMs
- KakaoTalk-style ordinary friend chats
- Local audio import and playback
- Notes and story-branch editor
- Local browser persistence

## Limitations
This is a single-device static prototype. GitHub Pages does not provide authentication, shared database or push notifications. Multi-user sync needs a backend such as Supabase/Firebase. Simulated calls only run while the page is open. Audio/image files must be selected by the user.
